# SKLAD - Учет материалов

У проектировщика много объектов и разрозненных Excel-файлов (заказы и отгрузки). Понять по ним реальный остаток на складе сложно. SKLAD собирает все заявки в одну базу и сама считает баланс (Заказано − Отгружено)

## 🚀 Установка и первый запуск (для проектировщика)

1. **Установите Python** (если он еще не установлен):
   * Скачайте Python 3.11 или выше с официального сайта [python.org](https://www.python.org/downloads/).
   * ⚠️ **ВАЖНО:** При установке обязательно поставьте галочку **«Add Python to PATH»** (в самом низу окна установщика).

2. **Скачайте и распакуйте проект**:
   * Скачайте ZIP-архив с этим проектом и распакуйте его в любую удобную папку (например, `D:\Складская_система`).

3. **Запустите систему**:
   * Дважды кликните по файлу **`SKLAD.bat`**.
   * ⏳ При первом запуске черное окно будет открыто 1-2 минуты (система автоматически скачает нужные библиотеки). Это нормально.
   * Когда в консоли появится `Application startup complete`, браузер откроется автоматически.

## 🛑 Как остановить систему
Просто закройте черное окно консоли (или нажмите в нём `Ctrl+C`).

## 💻 Как работать в системе

1. **Заказ на склад**: Загрузите Excel-файл с заявкой на закупку. Система проверит данные и добавит их на склад.
2. **Отгрузка со склада**: Загрузите файл на списание материалов. Система проверит, хватает ли товара, и не даст отгрузить лишнего.
3. **Склад**: Здесь отображаются текущие остатки всех материалов.
4. **Логи**: История всех загрузок и отгрузок с возможностью скачать исходный файл.
5. **Настройки**: Позволяют изменить папку, где хранится база данных (по умолчанию — в вашей папке «Документы»).

## 📄 Требования к файлам Excel
Имя файла должно быть в формате:
`Название объекта_Наименование заявки_Гггг.мм.дд.xlsx`
Пример: `ОП968_Профиль_2026.06.03.xlsx`

## 🛠️ Информация для разработчика

### Технологический стек
* **Язык**: Python 3.11+ (протестировано на 3.14).
* **Веб-фреймворк**: FastAPI + Uvicorn.
* **База данных**: SQLite + SQLAlchemy (ORM).
* **Работа с Excel**: Pandas + OpenPyXL.
* **Интерфейс**: Jinja2 + Bootstrap 5 (без тяжелых JS-фреймворков).

### Структура проекта
* `app/main.py` — точка входа, подключение роутеров и настройки.
* `app/routers/` — эндпоинты API (`api.py`) и HTML-страницы (`pages.py`).
* `app/services/` — бизнес-логика (парсинг Excel, расчет остатков, экспорт).
* `app/templates/` — HTML-шаблоны.
* `run.py` — скрипт запуска (автоматически активирует venv).

### Ручной запуск для разработки
Если вы хотите запустить проект вручную (без `.bat`):
```bash
# 1. Создать виртуальное окружение
python -m venv venv

# 2. Активировать его
venv\Scripts\activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Запустить
python run.py
